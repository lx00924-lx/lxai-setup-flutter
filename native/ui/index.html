卸载 LxAI

将从这台电脑上移除 LxAI。

将会删除

· 程序文件与内置的 Python 运行时；
· 桌面与开始菜单的快捷方式；
· 「应用和功能」里的卸载入口；
· 开机自动启动项（如果开过）。

将会保留

· 你的聊天记录、登录状态与全部设置（存在「文档」目录里）。
卸载一个客户端不该顺手把你的聊天记录也抹掉 —— 重新安装后会原样回来。
确实想彻底清空的话，卸载后手动删除「文档」下的 *_box.hive。
